Assignments and projects for the course.

Course description:
ECE 361 teaches intermediate C programming, data structures, and the tools a working engineer uses every
day. You will write reusable, maintainable C in the form of abstract data types and multi-file modules, and you
will build and manage it with gcc, make, the bash shell, and git/GitHub. The course introduces embedded
systems through memory-mapped I/O and a simulated temperature and humidity sensor. Data structures
covered include arrays, linked lists, stacks, queues, binary search trees, and hash tables.
AI coding tools now write much of this code on request. That makes the foundations more important, not less:
someone still has to specify what the code must do, read what comes back, find where it breaks, and explain
it. The course is built around that. Every week you practice the foundations by hand, without any tools. You
build, with AI if you choose. And you show, in conversation, that you understand what you built.
